# 💖 Happy Birthday, My Love | Special Romantic Birthday Surprise 🎂✨

A magical, interactive, romantic birthday experience built with pure HTML5, CSS3, and JavaScript.

## ✨ Features
- 🎁 **Interactive Gift Box:** Tap-to-open celebration surprise.
- 💘 **"Catch The Love" Mini-Game:** Collect floating romantic hearts with dynamic messages.
- 📜 **Typewriter Birthday Love Letter:** Romantic glowing typewriter reveal.
- 📸 **Polaroid Scrapbook & Memory Album:** Categorized polaroid photos with interactive fullscreen lightbox and video support.
- ⏳ **"Our Story" Interactive Timeline:** Milestones and special memories journey.
- 🌌 **Magical Night Sky & Sky Lanterns:** Ambient glowing moon and tap-to-release sky lanterns.
- 🎵 **Romantic Audio Engine:** Procedural music box "Happy Birthday To You" synthesizer with custom MP3 support.
- 📱 **100% Mobile Responsive:** Optimized for all screen sizes and touch devices.

## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/FurqanRafi/Birthday-Wish.git
   ```
2. Open `index.html` in your browser or run:
   ```bash
   npx serve .
   ```

## ⚙️ Customization
Edit `config.js` to customize:
- Names (`girlfriendName`, `partnerName`)
- Dates & Messages
- Photos & Videos in `public/` folder
- Audio / Background Music
